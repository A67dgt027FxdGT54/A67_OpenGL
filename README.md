This is a library which makes OpenGL easy, with the tutorial and documents (in Chinese).

这是一个简便、好用的 OpenGL 封装，可以让你创建窗口、渲染图形，并提供了配套教程和全套依赖库文件。

Only support Windows and GCC compiler.

仅支持 Windows 与 GCC 编译器。

### Dir. 目录

> OpenGL64/
> > header/ : the headers. 头文件。
> > > OpenGL.h : the header of main functions. 定义主要功能的头文件。
> > lib/ or lib64/ or lib32/ : binary files. 二进制文件。
> > log/ : log files. 日志。
> > sd_lib/ : Shader library. 着色器库。
> > 教程/ : tutorial. 教程。
