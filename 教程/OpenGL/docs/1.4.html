1.4 纹理

想象一下这样一个场景：你正在制作《Minecraft》，需要给每个像素不同的颜色，因此，你需要为每个方块创建3000余个三角形，性能开销太大，而且太麻烦了。假如像素更多一些，情况还会更糟。因此，你急需一种方式给三角形图案，这就是纹理。
纹理是一张贴在三角形上的图片。
我们通过以下代码创建一个纹理对象： texture_t tx(const char* img_path,bool _use_alpha,int _unit=0);
const char* img_path
：
图片的路径。
bool _use_alpha
：
历史原因，此为无效参数，忽略即可。填入任何参数均可。
int _unit
：
默认纹理单元（后面会讲），默认为0。

纹理坐标

为了让 OpenGL 知道我们要把图片贴在什么位置，我们需要给每个顶点指定：纹理上的哪个位置要贴在这个顶点上。这就是纹理坐标。
如图，左边是一张完整纹理的坐标，可以看见：
纹理坐标的原点为左下角，范围为 0~1。横轴为 X轴（S轴），纵轴为 Y轴（T轴）。
右边是它贴在一个三角形上的样子，可以看到每个点都有一个纹理坐标，纹理上对应的位置就被贴在顶点上。

例1.

以1.2课 ex1为基础，绘制一个带有res/box.jpg纹理的矩形。
首先，我们要定义一个纹理对象： texture_t tx("res/box.jpg",0)
在C++中，有默认值的参数，可以不填。此例中未填默认纹理单元。
然后调用此函数绑定纹理： tx.bind(); 还需要改变一下顶点属性，以供存放纹理坐标：（预留了颜色属性） 3 3 3 2 // 位置（坐标） 颜色 纹理坐标 -0.5 -0.5 0 1 0 0 0 0 0.5 -0.5 0 0 1 0 1 0 0.5 0.5 0 0 0 1 1 1 -0.5 0.5 0 1 1 0 0 1 相应改变顶点着色器，接收顶点属性，并转发至片段着色器： layout (location = 0) in vec3 v_pos; layout (location = 1) in vec3 v_col; layout (location = 2) in vec2 v_tex; out vec3 tcol; out vec2 ttex; tcol=v_col; ttex=v_tex; 并在片段着色器中接收： in vec3 tcol; in vec2 ttex; 然后在片段着色器中定义一个2D纹理（一定要是uniform）： uniform sampler2D tex; 之后给输出颜色赋值： fcol=texture(tex,ttex);
在片段着色器中调用 texture(2D纹理,纹理坐标) 可以得到当前绑定的纹理中，纹理坐标处的颜色。
我们还能将纹理和顶点颜色混合： fcol=texture(tex,ttex)*vec4(tcol,1.0f);
将多个颜色相乘可以实现混合这些颜色的效果。

纹理单元

纹理为什么会是 uniform 呢？因为我们可以给它赋一个整数值（范围 0-15），作为它的编号，也就是纹理单元。利用这个特性，我们可以同时绑定多个纹理。
上文中创建纹理代码的最后一个参数就是此纹理默认的单元，调用 tx.bind(); 可以将它绑定到默认单元，还可以调用 tx.bind(int unit); 将它绑定到另一个单元。

例2.

在 eg1 的箱子上贴一个笑脸图标（ res/face.png ）。 首先，我们要定义并绑定两个纹理对象：（笑脸有透明度） texture_t tx1("res/box.jpg",0,0); texture_t tx2("res/face.png",1,1); tx1.bind(); tx2.bind(); 然后修改片段着色器，声明两个纹理并改变颜色赋值： uniform sampler2D tex1; uniform sampler2D tex2; fcol=mix( texture(tex1,ttex), texture(tex2,ttex), 0.2 );
mix() 将两种颜色（前两个参数）按给定比例（最后一个参数，代表第二种颜色的比例）混合。
最后给 uniform 赋值为对应的单元： sd.seti("tex1",0); sd.seti("tex2",1); 完整代码 eg2

纹理环绕

那么，如果纹理坐标超出范围，会怎么样呢？
这就是用于解决以上问题的。定义在 gle 内。多种选项有不同的效果。
选项
：
效果
gle.tex_repeat
：
（默认）重复纹理图像。
gle.tex_mirrored_repeat
：
同上，但是每次重复都镜像放置。
gle.tex_clamp_to_edge
：
重复纹理的边缘。
gle.tex_clamp_to_border
：
外围均为用户指定的颜色。
如图所示。 我们通过以下代码设置： tx.wrap(GLenum mode_s,GLenum mode_t); 两个参数分别是 S轴(X轴) 和 T轴(Y轴) 的环绕模式。
通过以下全局函数指定 gle.tex_clamp_to_border 的颜色： tex_border_col(float r,float g,float b,float a); tex_border_rgb(unsigned int _rgb); tex_border_rgba(unsigned int _rgba); 使用方法同清屏函数。

纹理过滤

假如我们有一张低分辨率纹理需要显示，应该怎样显示呢？
gle.tex_fil_pixel
：
像素化显示。
gle.tex_fil_linear
：
（放大模式默认值）平滑（线性）地显示。
通过以下函数设置： tx.fil(GLenum mode_min,GLenum mode_mag); 其中，mode_min 代表纹理被缩小时的模式，mode_mag 代表纹理被放大时的模式。

多级渐远纹理

当纹理被缩小时，这样会产生很不真实的感觉，性能也不佳。因此，出现了 多级渐远纹理。如图，这像是大纹理的好多缩小版本。 多级渐远纹理会在创建纹理时自动生成。
它是在纹理被缩小时使用的，因此，你仅可以为 mode_min 指定以下的值：
tex_fil_**，星号处为两个字母。

l

纹理的本质
我们知道，片段着色器的输入会被进行插值，纹理坐标也一样。因此，我们调用 texture() 函数就是在纹理上找到对应像素的颜色。
