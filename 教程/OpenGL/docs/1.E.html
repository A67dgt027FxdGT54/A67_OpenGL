功能补充

篇幅限制，未能在正文中提及全部功能。

1. 网格缓冲数据更新（mesh_buf_t）

mb.upd_ve( vector<float> 新顶点 )
整体替换所有顶点数据（数据总量不变）。
mb.upd_in( vector<unsigned int> 新索引 )
整体替换所有索引数据（数据总量不变）。
mb.upd_ve_p( vector<float>& 部分顶点, int 起始顶点 )
从第 起始顶点 号开始替换部分顶点数据（可用于局部更新）。
mb.upd_in_p( vector<unsigned int>& 部分索引, int 起始索引 )
从第 起始索引 号开始替换部分索引数据（三角形索引更新）。
注意
使用 upd_ve_p 和 upd_in_p 时，新数据的大小必须与原始数据中对应部分的大小一致，否则可能导致内存访问错误。

2. 面剔除（gl_t）

还记得我们要求顶点为逆时针排列吗？这就是为这步优化准备的。
gl.cull_face(bool 启用)
启用/禁用面剔除。开启后，背对摄像机的三角形将不会被渲染，可提升性能（默认关闭）。
提示
面剔除依赖于顶点顺序。从正面观察时，顶点应为逆时针顺序。若发现模型“消失”，可检查顶点顺序或暂时关闭剔除。

3. 帧率锁定（timer_t）

tim.fslp()
在每帧末尾调用，使程序休眠以固定帧率（帧率由构造函数 timer_t(int fps) 设定）。
tim.curf
从程序启动到当前帧的总帧数（仅在调用 fslp() 后递增）。
