光照介绍

我们使用的是风氏光照算法。光照最终效果可以分解为三种效果的组合： 1. 环境光。在真实世界里，光线可以反射，甚至可以来回反射。完全模拟这个过程连最好的显卡也做不到。为了节省性能，我们使用一个环境光，来代表 这些多次反射的光线 照亮的一点点亮度。
2. 漫反射。光照在物体上，物体就会显示出它的颜色，这就是漫反射。
3. 镜面反射。光滑的物体，会映出光源的颜色，这就是镜面反射。
4. 将这些颜色混合，即为最终效果。

材质

物体有颜色，镜面光的样式也不一致。描述这些属性的对象就是材质。
我们在着色器中导入光照头文件：#include<phong.fsh> 然后声明一个材质对象：material_t mate; 它的成员有：

1.

vec3 mate.diff： 物体本身的颜色即漫反射光的颜色，也是漫反射的强度（在红绿蓝三个通道上的）。

2.

vec3 mate.spec： 物体高光的强度，也是高光的颜色。

3.

float mate.shini： 物体的反光度。（高光的范围，如图） 下图展示了各种材质的效果： img from here / LearnOpenGL

例2.

给例1的场景加上光照效果。

1. 材质

我们首先在着色器中创建一个材质： material_t mate; 然后思考一下怎样给它传数据。我们当然可以用 uniform，但是，我们常常需要在着色器中修改其属性，但 uniform 不能直接修改。因此，我们额外创建一个 uniform，赋值给原材质，就能修改那个作为普通变量的原材质了：uniform material_t u_mate; mate=u_mate; // 可以修改mate 下一个问题，怎么传结构体 uniform ？有两种方法： sd.set*("结构体.成员",***); sd.set*(sdu("结构体","成员"),***); 于是我们传入： sd.set3f("u_mate.diff",vec3(1.0f,0.5f,0.31f));// orange sd.set3f("u_mate.spec",vec3(1.0f,1.0f,1.0f)); // bright white sd.setf("u_mate.shini", 32.0f);

2. 光源

同样，我们创建一个光源：light_t lt;uniform light_t u_lt;lt=u_lt; 接下来就是把它传到着色器里了。不同的是，在C++侧也有一个相同的 light_t，我们创建一个： light_t lt; lt.type=1; lt.amb=vec3(0.2f,0.2f,0.2f); // dark white / gray lt.diff=vec3(0.5f,0.5f,0.5f);// mid white / gray lt.spec=vec3(1.0f,1.0f,1.0f);// bright white lt.kc=1.0f; lt.kl=0.09f; lt.kq=0.032f; 然后传数据：sd.setlight("u_lt",lt); 别忘了，lt.dir 还要自己算：（在片段着色器中） lt.dir=片段位置-光源位置; 那么我们接下来的任务就是获取这两个位置了。

1. 片段位置。

目前的所有位置都是在世界空间中的。我们可以在顶点着色器中，算出顶点在世界空间中的位置，插值后即为片段位置：
顶点着色器： out vec3 f_pos; f_pos=vec3(model*vec4(v_pos.xyz,1.0)); 片段着色器：in vec3 f_pos;

2. 光源位置。

直接传 uniform 就行。 uniform vec3 lt_pos; sd.set3f("lt_pos",lt_pos); 因此 lt.dir=f_pos-lt_pos;

3. 法向量

法向量是光线反射的轴，通常垂直于它所在的平面。它通常在顶点数据中定义。因此，我们需要替换 mb的顶点数据：res/cube_normal.ve。 （数据布局：3顶点坐标，3法向量，2纹理坐标）
然后经顶点着色器转发：layout (location = 1) in vec3 v_norm; out vec3 t_norm; 对法向量的变换，常常使用另一个矩阵：法线矩阵。在这里没有任何变化，故传入单位矩阵： uniform mat3 m_norm; sd.setm3("m_norm",mat3(1.0f)); t_norm=m_norm*v_norm; 最后在片段着色器中接收： in vec3 t_norm;

4. 相机位置

直接传。uniform vec3 cam_pos;sd.set3f("cam_pos",cam.pos);

最终调用

fcol=lighting(t_norm,cam_pos-f_pos,mate,lt); 终于好了eg2。

总结

结构体：material_t（材质）

vec3 diff
漫反射颜色（物体本身颜色），也是强度。
vec3 spec
镜面反射强度（RGB），也是颜色。
float shini
高光反光度（值越大高光越集中，推荐 8~128）。

结构体：light_t（光源）

int type
光源类型：0 方向光，1 点光源，2 聚光灯，-1 无效。
以下仅列举点光源属性。
vec3 dir
光源指向片段的向量（不应归一化）。
vec3 amb
环境光强度（RGB），也是颜色。
vec3 diff
漫反射强度（RGB），也是颜色。
vec3 spec
镜面反射颜色（高光颜色），也是强度。
float kc / kl / kq
衰减系数。

函数：lighting（光照计算）

函数调用
vec4 lighting(vec3 norm, vec3 v_dir, material_t materi, light_t lt);
norm
法线（需预先归一化）。
v_dir
视线方向，从片段指向摄像机（即摄像机坐标 - 片段坐标）。
materi
材质。
lt
光源。
返回值
最终光照颜色（vec4，alpha 固定为 1.0）。
