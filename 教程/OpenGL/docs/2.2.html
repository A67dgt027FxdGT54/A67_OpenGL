2.2 光照贴图

通常来说，一个物体的材质属性不总是一致：物体的表面有不同的颜色，钢铁和木头的镜面光强度也不一样（当然，漫反射颜色也不同）。所以，我们的目标就是，找到一种方式，给物体表面的每一个点，分别指定一个漫反射颜色，和一个镜面光强度。
不难发现，这和纹理很像。我们可以用一个纹理，贴在物体表面上，给表面上的每一个点指定一个属性。我们仅仅是不把 texture() 函数的返回值当成颜色，而是把它当成一个 vec3属性。
指定漫反射颜色的贴图（纹理），叫漫反射贴图；指定镜面光强度的贴图，叫做镜面光贴图。
注：纹理=贴图

漫反射贴图

由于漫反射也能表示物体原本的颜色，故可以直接使用物体的纹理。
图片：res/container2.png。这张图片有不透明度信息。加载时需将 _use_alpha 参数设为 1，否则图像解码会出错。

镜面光贴图

因为镜面光的强度通常对红、绿、蓝都是一致的，所以我们一般使用一张灰度（黑白）图片：res/spec.png。这张图片有不透明度信息。

例1.

使用光照贴图。
定义两个纹理： texture_t diff_tx("res/container2.png",1,0), spec_tx("res/spec.png",1,1); 初始化时绑定两个纹理： diff_tx.bind(); spec_tx.bind(); 在片段着色器中定义纹理：uniform sampler2D diff_tex,spec_tex; 在顶点着色器中转发纹理坐标： layout (location = 2) in vec2 v_tex; out vec2 t_tex; t_tex=v_tex; 在片段着色器中给 mate.diff/spec 赋值为纹理数据： in vec2 t_tex; mate.diff=vec3(texture(diff_tex,t_tex)); mate.spec=vec3(texture(spec_tex,t_tex)); //texture() 返回四分量（RGBA），用 vec3() 只取 RGB 作为颜色，丢弃透明度通道。 替换材质设置，给纹理 uniform 赋值： // set mate sd.seti("diff_tex",0); sd.seti("spec_tex",1); sd.setf("u_mate.shini", 32.0f); 如果你成功了，你会发现箱子的铁框有反光，木板则没有。eg1。
为何我们通常不用彩色的spec贴图呢？你可以试着把spec贴图替换为res/col_spec.png，就能发现效果不怎么真实。
