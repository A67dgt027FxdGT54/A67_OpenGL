文档

一、核心类型与常量（gle）

gle 是库预定义的一个全局对象，存放常用的 OpenGL 枚举值，方便记忆和书写。

1. 数据使用模式（构造网格缓冲时使用）

gle.draw_never_chg
数据几乎不变（静态模型）
gle.draw_often_chg
数据经常改变（动态物体）
gle.draw_always_chg
数据每帧都变（粒子系统）

2. 纹理环绕模式（tx.wrap）

gle.tex_repeat
重复纹理（默认）
gle.tex_mirrored_repeat
镜像重复
gle.tex_clamp_to_edge
拉伸边缘像素
gle.tex_clamp_to_border
边框填充指定颜色

3. 纹理过滤模式（tx.fil）

gle.tex_fil_pixel
最近邻采样（像素风）
gle.tex_fil_linear
线性插值（平滑，放大时默认）
缩小模式（mode_min）
可使用组合：gle.tex_fil_ll（默认）、gle.tex_fil_lp、gle.tex_fil_jl、gle.tex_fil_jp
第一个字母：l（精确选择mipmap级别）/ j（近似选择）
第二个字母：l（线性过滤）/ p（像素过滤）

二、窗口与主循环（gl_t）

构造函数

gl_t gl(bool 使用OpenGL3.3, int 宽度, int 高度, const char* 标题);

成员

winw, winh 为窗口的宽、高。

成员函数

gl.main_loop()
进入主循环，每帧自动调用用户定义的 show() 函数。
gl.close_win()
请求关闭窗口（在 show() 中调用）。
gl.kpr(按键常量)
检测指定按键是否被按下（返回 bool）。
gl.kprf(按键常量)
检测按键是否刚被按下（仅触发一次），返回 bool。用于检测单次按键
gl.clr_col(r,g,b,a) / gl.clr_rgb(0xRRGGBB) / gl.clr_rgba(0xRRGGBBAA)
清屏并填充指定颜色。
gl.triangle(int 起始索引, int 三角形数)
绘制三角形（需先绑定网格缓冲和着色器）。
gl.dept(bool 启用)
启用/禁用深度测试（3D渲染必须开启）。
gl.blend(bool 启用)
启用/禁用透明度混合（默认开启）。
gl.cull_face(bool 启用)
启用/禁用面剔除（优化性能）。
gl.mouse()
启用鼠标捕获并设置回调（配合 mousectrl_t 使用）。
gl.mouse_cb()
仅设置鼠标回调（不隐藏鼠标），用于非捕获模式。
gl.line() / gl.fill()
切换为线框模式 / 填充模式（调试用）。
gl.w_div_h()
返回窗口宽高比（用于透视投影计算）。
gl.set_win(int 宽, int 高)
在 framebuffer_size_callback 中调用，更新内部宽高记录。

三、网格缓冲（mesh_buf_t）

构造函数

mesh_buf_t mb(const char* ve文件, const char* in文件, GLenum 使用模式); mesh_buf_t mb(ve_t& 顶点对象, in_t& 索引对象, GLenum 使用模式, bool 忽略);

成员函数

mb.bind()
绑定此网格缓冲，后续绘制将使用其数据。
mb.clr()
释放所有数据内存。
mb.upd_ve(...) / mb.upd_in(...) / mb.upd_t(...)
整体更新顶点/索引数据（详见本章第一节）。
mb.upd_ve_p(...) / mb.upd_in_p(...)
局部更新部分顶点/索引数据（性能更优）。
mb.read_vi(ve文件, in文件)
从文件加载顶点和索引数据（替换当前数据）。
mb.upload(gle.[...])
将当前数据上传至 GPU。
mb._ve / mb._in
顶点数据对象和索引数据对象（可直接修改）。

四、纹理（texture_t）

构造函数

texture_t tx(const char* 图片路径, bool 忽略, int 默认纹理单元=0);

成员函数

tx.build(...)
参数及功能同构造函数。
tx.bind()
绑定到默认纹理单元。
tx.bind(int 单元编号)
绑定到指定的纹理单元（0~15）。
tx.wrap(GLenum S轴模式, GLenum T轴模式)
设置纹理坐标超出范围时的行为（见 gle 常量）。
tx.fil(GLenum 缩小模式, GLenum 放大模式)
设置纹理缩放时的过滤方式（见 gle 常量）。

公开成员

pw, ph
纹理宽度、高度（像素）。
un
默认纹理单元编号。
chan
通道数（1/3/4）。

全局边框颜色函数

tex_border_col(float r,g,b,a)
设置 clamp_to_border 模式的边框颜色（0~1）。
tex_border_rgb(0xRRGGBB)
同上，使用十六进制（不含透明度）。
tex_border_rgba(0xRRGGBBAA)
同上，包含透明度。

五、着色器（shader_t）

构造函数

shader_t sd(const char* 顶点着色器路径, const char* 片段着色器路径);

成员函数

sd.use()
激活此着色器程序。
sd.setb("变量名", bool)
传递布尔值 uniform。
sd.seti("变量名", int)
传递整数 uniform（纹理单元编号用此函数）。
sd.setf("变量名", float)
传递单精度小数 uniform。
sd.set2f/set3f/set4f(...)
传递 vec2 / vec3 / vec4 向量 uniform（支持重载）。
sd.setm3("变量名", mat3) / sd.setm4("变量名", mat4)
传递 3x3 / 4x4 矩阵 uniform（用于法线矩阵或 MVP 矩阵）。
sd.setlight("变量名", lt) / sd.setlight_array("数组名",下标, lt)
传递光源/光源数组 uniform。

其他

sdu(string uniform数组名,int 下标); sdu(string uniform数组名,int 下标,string 成员); sdu(string uniform数组名,string 成员); 用于替换 "变量名" ，以传递 数组、结构体数组、结构体 uniform。
GLSL详见 十二、着色器语言。

六、变换（trans_t）

trans_t tr;
tr.trans(vec3 位移)
设置平移量。
tr.rot(vec3 轴, float 角度)
绕任意轴旋转（角度制，遵循右手定则）。
tr.rote(vec3 欧拉角, string 顺序="YXZ")
按欧拉角旋转（角度制，默认按 Y-X-Z 顺序）。
tr.scale(vec3 缩放) / tr.scale(float 统一缩放)
设置缩放倍数。
tr.rad = true/false
切换角度制（false）与弧度制（true），默认为 false。
tr.matr()
返回组合后的 4x4 变换矩阵（顺序固定：缩放 → 旋转 → 平移）。

七、摄像机（camera_t）

camera_t cam(vec3 位置, float 偏航=-90, float 俯仰=0, float 滚转=0);

位置与视角控制

cam.pos
摄像机位置（可直接修改）。
cam.cplim
俯仰角限制（默认 89°）。
cam.set_yaw/pitch/roll(float 角度)
分别设置三个欧拉角（角度制）。
cam.get_yaw/pitch/roll/front/right/up()
获取当前角度值/方向（前、右、上）向量。
cam.mov_look(vec2 偏移量, bool 限制俯仰=true)
根据鼠标偏移量改变视角（乘以灵敏度 cam.sensit）。
cam.scl_look(float 滚轮偏移, float 最小FOV=1, float 最大FOV=45)
改变视场角（实现缩放效果）。

移动（需传入时间差 dt）

cam.movef(float dt)
向前方移动（速度 cam.mov_spd）。
cam.mover(float dt)
向右方移动。
cam.moveu(float dt)
向绝对上方（沿世界空间正Y轴）移动。
cam.keepy = 1
锁定 Y 轴高度（防止俯仰时“飞起来”）。moveu不受限制。
cam.view()
返回观察矩阵（View Matrix）。

八、计时器（timer_t）

timer_t tim; // 默认不限帧率 timer_t tim(int 目标帧率); // 配合 fslp() 使用
tim.cur
从程序启动/上次重置到当前帧的总时间（秒）。
tim.dis
上一帧到本帧的时间差（秒，用于速度平滑）。
tim.abso
自程序启动的绝对时间（秒）。
tim.offs
cur与abso之差
tim.fps / tim.curf
目标帧率 / 当前帧计数（内部使用）。

tim.upd()
在每帧开头调用，更新时间（必须调用）。
tim.fslp()
在每帧末尾调用，将帧率锁定为构造时设定的值。
tim.clear()
重置定时器。将 cur 设为 0。

九、数据结构（ve_t / in_t）

顶点数据（ve_t）

int mloc
顶点属性数量。
vector<int> siz
每个属性的分量数（如 3 表示 vec3）。
vector<float> data
按顶点顺序连续存储的所有属性数据。
clr()
清空数据释放内存。
ve.append(vector<float>)
追加顶点数据。
ve.calc_sum()
计算单个顶点总分量数（mloc 和 siz 决定）。

索引数据（in_t）

vector<unsigned int> data
每三个一组构成一个三角形（顶点编号）。
clr()
清空数据释放内存。
in.append(vector<unsigned int>)
追加索引数据。

十、鼠标控制（mousectrl_t）

mousectrl_t g_mouse;
g_mouse.init(float xpos, float ypos)
在 mouse_callback 开头调用，消除首次跳跃。
g_mouse.set(float xpos, float ypos)
记录当前鼠标位置（每帧调用）。

十一、全局数学函数与运算符

persp(fov, aspect, near, far)
生成透视投影矩阵（aspect 通常用 gl.w_div_h()）。
ortho(left, right, bottom, top, near, far)
生成正交投影矩阵。
~vec2/vec3/vec4
向量标准化（长度变为1，方向不变）。
u ^ v
计算两个向量之间的夹角（返回角度制数值）。
vec4 *= mat4
将矩阵左乘向量（等价于 vec = mat * vec）。
void norma(float& ang);
将角度归一化到 (-180, 180] 范围内，用于处理累计角度溢出
transd() / transr()
已废弃，恕不提供用法

十二、着色器语言

1. 基本结构

#version 330 core // 变量声明 void main() { // 执行逻辑 }

2. 变量限定符

in
输入变量。顶点着色器中用 layout (location = N) in 获取顶点属性。
out
输出变量，传递至下一阶段。片段着色器必须定义恰好一个 out vec4 作为最终颜色。
uniform
CPU 端传入的全局只读数据，所有着色器共享。

3. 核心数据类型

float / int / bool / uint
标量。
vec2 / vec3 / vec4
向量。
mat2 / mat3 / mat4
矩阵。
sampler2D
纹理（用于 uniform ）

4. 分量访问与重组

坐标
.x .y .z .w
颜色
.r .g .b .a
纹理坐标
.s .t .p .q
重组示例
someVec.xxyz、anotherVec.rgb（可任意组合）

5. 内置变量（顶点着色器）

gl_Position
输出标准化设备坐标（NDC），w 分量通常设为 1.0。

6. 常用内置函数

texture(纹理, 纹理坐标)
返回纹理上某个坐标的颜色（vec4）。
mix(a, b, t)
线性混合两个值（t 为 b 的比例）。
normalize(v)
将向量标准化（长度为 1）。
dot(u, v)
点乘（返回标量）。
cross(u, v)
叉乘（仅限 vec3，返回 vec3）。
reflect(I, N)
反射向量（用于镜面高光）。
clamp(x, min, max)
将 x 限制在 [min, max] 区间。
radians(deg) / degrees(rad)
角度与弧度互转。
pow(x, y)
计算 x 的 y 次幂。
注意事项
未使用的 uniform 变量会被编译器静默移除，可能导致传递失败。
片段着色器中只能有一个 out 变量（作为最终颜色输出），不可多写。

7. 着色器数学库 <math.ash>

求两向量夹角（角度制）
float angle(vec2 v1, vec2 v2);
float angle(vec3 v1, vec3 v2);
float angle(vec4 v1, vec4 v2);

8. 着色器光照库 <phong.fsh>

结构体：material_t（材质）

vec3 diff
漫反射颜色（物体本身颜色），也是强度。
vec3 spec
镜面反射强度（RGB），也是颜色。
float shini
高光反光度（值越大高光越集中，推荐 8~128）。

结构体：light_t（光源，注意C++中也有相同的结构体）

vec3 dir
方向光的光源方向，或点光源/聚光灯下光源指向片段的向量（不应归一化）。
vec3 spot_dir
聚光灯的主轴方向（仅聚光灯使用）。
vec3 amb
环境光强度（RGB），也是颜色。
vec3 diff
漫反射强度（RGB），也是颜色。
vec3 spec
镜面反射颜色（高光颜色），也是强度。
float kc / kl / kq
衰减系数，仅点光源和聚光灯有效。
float icutoff / ocutoff
聚光灯内/外裁剪角（角度制），仅聚光灯有效。
int type
光源类型：0 方向光，1 点光源，2 聚光灯，-1 无效。
衰减系数
由你想让光线传播直到完全衰减的距离决定。
